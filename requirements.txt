# --- Firestore: версії зафіксовані навмисно ---
#
# У google-api-core 2.35.0 зламано звернення до бази за замовчуванням: ім'я
# `(default)` йде на сервер URL-закодованим, і кожен запит падає з
#     InvalidArgument: 400 Invalid database id %28default%29
#
# Наслідок для бота фатальний: aiogram читає FSM-стан на КОЖНОМУ апдейті, тож
# ламається все — і воронка реєстрації, і команди, і повідомлення в групах.
# Стороннім оком це виглядає як «бот зламався після дати народження», хоча дата
# ні до чого: просто саме тоді збірка вперше підтягнула нову версію.
#
# Перевірено відтворенням:
#     api-core 2.31.0–2.34.0  →  працює
#     api-core 2.35.0         →  падає (з будь-якою версією firestore)
#
# Firestore тут вказаний явно, хоч і приходить транзитивно через firebase-admin:
# інакше він невидимий у залежностях, і саме тому регресію не було з чим звірити.
google-api-core>=2.31.0,<2.35.0
google-cloud-firestore>=2.28.0,<3.0.0
